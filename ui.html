  O que cada palavra dessa tela quer dizer
  

    
fronteira A lista aberta: nós já gerados que ainda não foram
      abertos. Trocar de algoritmo é só trocar quem sai daqui primeiro.

    
expandir um nó Tirá-lo da fronteira, testar se é objetivo e, se não for,
      chamar successors() para gerar os filhos.

    
env() A assinatura de texto do estado. Dois estados com o mesmo
      env() são, para a busca, o mesmo estado — por isso ele precisa conter
      tudo que distingue um estado do outro.

    
poda O que fazer com um sucessor já conhecido. without: nada,
      a árvore repete estados sem parar. father-son: descarta se for igual ao pai.
      general: descarta se o env() já apareceu antes.

    
g, h, f g é o custo gasto até o nó; h é o seu palpite
      do que ainda falta (o método h()); f = g + h é o que o A* usa
      para escolher.

    
limite m Profundidade máxima que a busca limitada aceita. Baixo demais e ela
      devolve None mesmo existindo solução.

    
máx nós Freio do visualizador, não da teoria: ele para de gerar depois desse
      tanto para o navegador não travar. Bater no teto é sinal de que falta poda.

    
caixinha da árvore Cada caixa é um nó, rotulada com o env() do
      estado. A borda azul marca o nó que está sendo expandido agora; a seta na aresta é o
      operator que gerou o filho.
